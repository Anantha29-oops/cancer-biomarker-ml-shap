🧬 About the Project

This project uses Machine Learning and Explainable AI to identify potential cancer biomarker candidates from RNA-seq gene expression data. TCGA cancer samples and GTEx normal tissue samples are processed and used to train classification models. Feature selection reduces the high-dimensional gene-expression data to the most informative 2,000 genes. XGBoost is used as the primary prediction model, while SHAP is used to explain which genes contribute most strongly to an individual prediction.

📊 Dataset TCGA + GTEx RNA-seq gene-expression data
🤖 Prediction XGBoost-based cancer classification
🔍 Feature Selection 2,000 informative gene features
💡 Explainability SHAP-based interpretation of model predictions
